# Despesas

App (PWA) para um grupo pequeno dividir despesas em várias moedas: quem pagou, quem
participa e quem deve a quem, em cada moeda, sem conversão.

Para usar, abra o link de convite do seu grupo.

```
app/    o app, publicado no GitHub Pages
gas/    o servidor (Google Apps Script): Code.js e Calc.js
```
